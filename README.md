# 📱 PostIt 

![PostIt Banner](https://img.shields.io/badge/PostIt-Social_Media_App-blue)
![React](https://img.shields.io/badge/React-19.2.0-61DAFB?logo=react)
![Vite](https://img.shields.io/badge/Vite-7.2.4-646CFF?logo=vite)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-4.1.18-38B2AC?logo=tailwind-css)

A modern social media application built with React and Tailwind CSS. Share posts, engage with content, and connect with others in real-time.

## 🌟 Live Demo

**Live Application:** [https://postit-app.vercel.app](https://post-it-bhg2.vercel.app/)  

## ✨ Features

### 🔐 Authentication & Security
- **User Registration & Login** with JWT token-based authentication
- **Secure Password Change** with confirmation validation
- **Profile Picture Management** with image upload
- **Secure Session Management** with localStorage
- **Protected Routes** for authenticated users only

### 📝 Post Management
- **Create, Edit & Delete Posts** with rich text content
- **Image Upload** for visual content
- **Character Counter** with 300 character limit
- **Post Sharing** with custom captions
- **Bookmark Posts** for saving content to read later

### 💬 Social Interactions
- **Real-time Comments** with nested replies 
- **Comment Editing & Deletion** with user permissions
- **Comment Likes** with toggle functionality
- **Image Attachments** in comments and replies
- **Reply System** with nested comment threads

### ❤️ Engagement Features
- **Like/Unlike Posts** with real-time counter updates
- **Bookmark/Unbookmark Posts** for saving content
- **Share Posts** with custom messages
- **Follow/Unfollow Users** with real-time updates
- **Activity Notifications** for follows, likes, and comments

### 🔔 Notifications System
- **Real-time Notifications** for user interactions
- **Unread Count Badge** showing pending notifications
- **Mark Single or All Notifications** as read
- **Rich Notification Content** with user avatars and previews
- **Click-to-Action** notifications that navigate to relevant content
- **Responsive Dropdown** with mobile-optimized design

### 👤 User Profiles
- **Profile Picture Upload & Update** with instant preview
- **User Profile Viewing** with follow/unfollow capability
- **Activity Timeline** showing user's posts
- **Follower & Following Counts** displayed on profiles
- **Follow Suggestions** with personalized recommendations

### 📱 User Interface
- **Modern Glassmorphism Navbar** with scroll effects
- **Responsive Sidebar** with mobile-optimized navigation
- **Active Tab Highlighting** for better navigation
- **Follow Suggestions Sidebar** with click-to-follow
- **Bookmarks Page** for saved posts
- **Smooth Animations** and transitions

### 🛠️ Technical Features
- **Responsive Design** for all screen sizes (mobile, tablet, desktop)
- **Optimized Performance** with React Query caching
- **Form Validation** with React Hook Form & Zod
- **Error Handling** with user-friendly toast notifications
- **Loading States** with skeleton screens
- **Image Preview** before upload
- **Password Visibility Toggle** for better UX
- **Automatic Query Invalidation** for real-time updates
